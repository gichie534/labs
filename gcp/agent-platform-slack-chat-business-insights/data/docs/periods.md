# Reporting periods

All timestamps are UTC, and periods are calendar periods in UTC.

- **This month** = from the first day of the current month up to now (month-to-date).
- **Last month** = the previous full calendar month.
- **The month before (last month)** = the full calendar month before last month.
- **This week / last week** = ISO weeks, Monday to Sunday.
- **Last N days** = the N full days before today. Today isn't included.

## Comparisons ("trend", "compared to", "versus")

- **Last month vs the month before** compares two full calendar months.
- **This month vs last month** compares month-to-date with the **same number of days** at the start of
  last month. Never compare a partial month with a full one.
- Report the absolute values for both periods, the absolute change and the change in percent:
  `(current - previous) / previous`, rounded to one decimal.
- Call a change **flat** when it is within ±2%.
